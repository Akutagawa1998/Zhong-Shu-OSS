# MAP — project locations and source authority

| Location | Role / authority | Availability and observed time | New location after migration |
|---|---|---|---|

## Rules
- One canonical writable memory hub; external folders are sources or artifacts.
- Record source precedence and unresolved contradictions explicitly.
- Relative locations resolve from this hub unless a row states otherwise.
- Remote workers return artifacts, not competing writable hubs.
- Claims and operating permissions are never inherited from another project.
